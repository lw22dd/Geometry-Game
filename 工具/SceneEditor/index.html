导出地图数据

编辑器只产出标准地图数据（版本化 JSON）。点击「复制代码」使用；或切换查看 MapDefinition TS 兼容视图。

从游戏源码导入地图

选择一张游戏 config/level.ts 中的现有地图，decompile 为编辑器格式进行逆向编辑。

从模板新建地图

选择一个地图模板作为起点。模板以独立副本载入，不会影响模板本身。

保存当前地图为模板

保存路径固定为 src/mapTemplate/（所有地图的默认保存路径）。需以 npm run dev 启动编辑器；写入失败时自动回退为浏览器 localStorage 模板。
